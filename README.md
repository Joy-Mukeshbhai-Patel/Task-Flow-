# TaskFlow - Modern Glassmorphic To-Do & Productivity Manager 🚀

TaskFlow is a sleek, feature-rich, high-performance web application designed for personal productivity and daily office task management. Built with vanilla HTML5, CSS3, and ES6 JavaScript, it features a glassmorphic dark theme, star galaxy glowing background, real-time analytics, task priorities, categories, and full `localStorage` persistence.

🌐 **Live Demo**: [https://joy-mukeshbhai-patel.github.io/taskflow/](https://joy-mukeshbhai-patel.github.io/taskflow/)

---

## ✨ Features

- **🎨 Modern Glassmorphic UI**: Deep ambient star galaxy glow, backdrop blur panels, and smooth micro-interactions.
- **📊 Real-Time Analytics Dashboard**: Live task counters (Total, Active, Completed) with an animated completion progress bar.
- **🏷️ Categories & Priorities**:
  - **Priority Levels**: High 🔴, Medium 🟡, Low 🟢
  - **Categories**: 💼 Work, 🏠 Personal, 💪 Fitness, 📚 Study, 💡 Ideas
- **📅 Due Dates & Overdue Alerts**: Date pickers with relative formatting ("Today", "Tomorrow", "Overdue") and color highlights.
- **⭐ Star & Favorite Tasks**: Quick starring to highlight top-priority goals.
- **🔍 Real-Time Search, Filtering & Sorting**:
  - Search by task title.
  - Filter by status (*All*, *Active*, *Completed*, *Starred*) or specific categories.
  - Sort by creation date, due date, or priority.
- **✏️ Modal Task Editing**: Comprehensive edit modal for updating title, category, priority, and due date.
- **🔔 Toast Notifications & Sound FX**: Instant visual feedback for task actions.
- **💾 LocalStorage Persistence**: Automatically saves state so your data persists across browser reloads.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic document structure & accessibility attributes.
- **CSS3**: Vanilla CSS design system, CSS custom properties (variables), glassmorphism, responsive grid layout, and keyframe animations.
- **JavaScript (ES6+)**: Modular state management, dynamic DOM rendering engine, search/sort algorithms, and localStorage sync.

## 🚀 Getting Started

### Running Locally
1. Clone or download this repository.
2. Open [`index.html`](index.html) in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, open the project in VS Code and use the **Live Server** extension.
